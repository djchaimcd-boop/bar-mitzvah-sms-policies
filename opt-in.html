This is a personal, non-commercial program. Chaim Leshinsky uses it to collect guest names and mailing addresses from family members and friends so that invitations to one family bar mitzvah can be addressed and mailed.

There is one opt-in path, and it is user-initiated

There is no web form, no checkbox, and no purchased or imported list. The only way anyone joins is by sending a text message to the program number themselves.

  1. Chaim Leshinsky gives the program number to a family member or friend privately — by personal text message, or in person by word of mouth. The wording used is reproduced in full below.
  2. That person decides whether to participate. If they do, they send the first text message to (732) 410-4268, typically a guest's name.
  3. That inbound message is their consent. The program then replies to confirm what was recorded.

No phone number is ever messaged unless that number texted the program first. The system has no ability to send to a number that has not written in, and no numbers are added by the operator by hand.

Exact call-to-action wording

This is the verbatim invitation that Chaim Leshinsky sends privately, or reads aloud when inviting someone in person:

Chaim Leshinsky here. Text guest names to 732-410-4268 to add them to the bar mitzvah list. You'll get a reply confirming each name. Msg & data rates may apply. Reply STOP to opt out, HELP for help.

Message frequency and rates

Message frequency varies and is driven entirely by the participant's own activity: one reply for each message they send, plus a totals message when they ask for one. There are no scheduled, recurring, or broadcast messages. Message and data rates may apply, depending on the participant's mobile plan.

Opting out and getting help

STOP
Ends participation immediately. The participant receives a single confirmation and then no further messages.
HELP
Returns instructions along with the sender's name and the contact email djchaimcd@gmail.com.

Standard opt-out keywords are all honored: STOP, STOPALL, UNSUBSCRIBE, CANCEL, END and QUIT. A participant who has opted out can rejoin by texting START.

What is done with the information

Guest names and mailing addresses that participants text in are stored in a private database used only to print address labels for this one event's invitations. Nothing is sold, shared, or used for marketing. Full detail is in the Privacy Policy.
